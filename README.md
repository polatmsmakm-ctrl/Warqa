# ورقتي (Warqa)

تطبيق آيفون بفكرة كانفا: صفحات سادة / ٤ أسطر / مسطّرة / مربعات، ألوان، صور، نصوص عادية ومنقّطة، وأشكال (مربع، دائرة، سهم، خط).

## بناء الـ IPA
1. ارفع محتوى هذا المجلد لريبو جديد على GitHub (فرع main).
2. Actions ← Build IPA ← Run workflow (أو يشتغل تلقائياً مع أول push).
3. نزّل الـ artifact باسم Warqa-ipa، فك الضغط، وثبّت Warqa.ipa بـ Sideloadly.
